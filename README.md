Token launch radar ranking 197 pre-token protocols by implied value. The value model is derived from the snapshot's own figures — live-token mcap/TVL comparables per category, 7-day growth, and time with no token — separating token-trading protocols from pre-token ones. The dashboard is sortable and filterable, with a model breakdown and a concrete farm plan for every protocol.

## Run it

```sh
node main.ts --input input --output out
```
